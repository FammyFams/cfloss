# cfloss.com

Waitlist page for cfloss. Plain HTML/CSS/JS with no build step, served by GitHub Pages from `main` (root) at [cfloss.com](https://cfloss.com).

Sign-ups post to a Google Form (field `entry.353446030`). If the form's Email question is ever recreated, update the field name in `index.html`.

Run locally:

```bash
python -m http.server 8000
```
